# PaddockPath plugins

Plugins that bring a company's PaddockPath records into their own Claude, read-only.

- [PaddockPath Feedlot](./paddockpath-feedlot): a feedlot's records, with a skill for each report feedlots
  make again and again, laid out in PaddockPath's look.

Add one from Claude's directory, or in Claude Code run
`/plugin install paddockpath-feedlot --marketplace Quinence/paddockpath-plugins`. Each plugin's README says what it
reads and sends, and its LICENSE the terms it is used under.
